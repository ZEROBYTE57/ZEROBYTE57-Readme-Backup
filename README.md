## 🚀 Projects

| Title | What it does | Type | Status |
|---|---|---|---|
| [**CXB: Connectome eXplanation Benchmark**](https://github.com/ZEROBYTE57/GNN-in-Medical-Imaging/tree/main/CXB) | M.Tech dissertation. Plants known disease effects and realistic scanner-site artefacts into real ABIDE brain connectomes, then tests whether GNN explainers recover the disease or the scanner. Proposes **SiteSwap**, a GNN whose explanations stay stable across site-swapped copies of each subject. Connectomes built for 848 subjects from 19 sites. | Research | 🚧 In progress |
| [**LLM Classification Fine-Tuning**](https://github.com/ZEROBYTE57/LLM-Classfication-Finetuning) | Kaggle Chatbot Arena task: predict which of two LLM answers a human preferred (3-class, log-loss). EDA over 64 models, a leakage bug found and fixed, and a validated baseline submission. | Personal | 🚧 In progress |
| [**SMOTE-MVDCNN**](https://github.com/ZEROBYTE57/SMOTE-MVDCNN) | Multi-view deep CNN for mammogram classification on CBIS-DDSM, with SMOTE-based view completion, hybrid class balancing and patient-level splits. Code rebuilt from the thesis report. | Research | ✅ Completed (Dec 2025) |
| [**Road Object Detection**](https://github.com/ZEROBYTE57/intelunnati_INTEL-Trio) | YOLOv3 / Darknet-53 detector for road scenes on the Indian Driving Dataset (Intel Unnati program), with a project report and demo video. | Program project | ✅ Completed |

## 🧭 Areas I've worked in

- 🕸️ **Graph neural networks:** brain connectome graphs, patient population graphs (GCN, GAT, GIN, graph transformers)
- 🔍 **Explainable AI:** testing whether model explanations find real signal or shortcuts
- 🧠 **Neuroimaging:** ABIDE fMRI connectomes
- 🩻 **Medical imaging:** mammography (CBIS-DDSM)
- ⚖️ **Imbalanced learning:** SMOTE view completion, hybrid class balancing
- 🚗 **Computer vision:** YOLOv3 object detection on Indian road scenes
- 💬 **NLP / LLMs:** human-preference prediction, pairwise text classification
- 🧪 **Rigorous evaluation:** leakage-free protocols, domain-shift and robustness benchmarks
- 💻 **Software engineering foundations:** algorithms and data structures in Java, and client web development (WordPress, HTML, CSS, JavaScript)
